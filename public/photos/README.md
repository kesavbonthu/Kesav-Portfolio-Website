# Portfolio photos

Add a web-sized photo (1600px on the long edge) and a small thumbnail in this folder. Add their paths, descriptive alt text, caption, and image dimensions to `data/hobbies.ts`. Array order determines slideshow order. Commit and push to publish through GitHub Pages.

The slideshow crossfades every five seconds while visible, pauses on hover or keyboard focus, and stops after manual navigation. Visitors can choose thumbnails, use previous/next buttons or arrow keys, and pause/play. Reduced-motion preferences disable autoplay and transitions. Click a photo to enlarge; Escape or the close button dismisses it.
