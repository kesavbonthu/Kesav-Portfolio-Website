# Portfolio photos

1. Place your own web-sized JPG, PNG, or WebP images in this folder. Aim for 1600px on the long edge and under 500 KB per photo; remove location metadata if unwanted.
2. Add an entry to `data/hobbies.ts` with the public path, descriptive alt text, optional caption, and actual width/height.
3. Commit and push the images and data changes to deploy them through GitHub Pages.

Photos appear in array order below Hobbies. Visitors can click to enlarge, press Escape to close, or use the close button. The gallery stays hidden until photos are added. This is a published gallery, not a browser-only upload preview.
