# Portfolio photos

Add a web-sized photo (1600px on the long edge) and a small thumbnail in this folder. Add their paths, descriptive alt text, caption, and image dimensions to `data/hobbies.ts`. Array order determines slideshow order. Commit and push to publish through GitHub Pages.

The slideshow plays automatically while visible, sliding horizontally every five seconds with a prominent center photo and faded neighboring previews. There are no navigation controls or thumbnails. Reduced-motion preferences disable autoplay and transitions. Photos are display-only and do not expand when clicked.
