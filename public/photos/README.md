# Portfolio photos

Add a web-sized photo (1600px on the long edge) and a small thumbnail in this folder. Add their paths, descriptive alt text, caption, and image dimensions to `data/hobbies.ts`. Array order determines slideshow order. Commit and push to publish through GitHub Pages.

The slideshow plays automatically while visible, with a gentle 1.8-second crossfade every five seconds. There are no navigation controls or thumbnails. Keyboard focus and the enlarged viewer pause playback; reduced-motion preferences disable autoplay and transitions. Click a photo to enlarge; Escape or the close button dismisses it.
